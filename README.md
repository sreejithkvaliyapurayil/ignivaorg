# IGNIVA Group website

Static GitHub Pages site for www.ignivagroup.com. No build step.

To preview, run `python3 -m http.server 8000` in the extracted directory and open http://localhost:8000/.

To deploy, upload the extracted files and assets directory to the root of the ignivaorg GitHub Pages publishing branch. The included CNAME specifies the existing custom domain, www.ignivagroup.com.

The contact page opens a draft in the visitor's email app. The website does not collect or store submitted information.
