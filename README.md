# IGNIVA Group website

Static GitHub Pages site for www.ignivagroup.com.

Upload the extracted package to the root of the ignivaorg repository and commit to the Pages publishing branch. In GitHub, open Settings → Pages, choose Deploy from a branch, and select the publishing branch and /(root). Set the custom domain to www.ignivagroup.com.

At the domain registrar, set the DNS CNAME record for host `www` to `sreejithkvaliyapurayil.github.io`. Use the hostname without a scheme or repository path. Enable Enforce HTTPS in GitHub Pages once the domain check and certificate are ready.

Cochin Trade Centre images are visualisations from the supplied masterplan and The Gathering Canvas brochure. The public website includes venue details and selected visuals.
